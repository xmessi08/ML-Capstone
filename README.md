# ML Capstone Project (Пайплайн машинного обучения)

Учебный проект по созданию воспроизводимого пайплайна машинного обучения на Python с использованием библиотек `scikit-learn`, `pandas` и тестов на `pytest`.

---

## 🛠 Какие библиотеки используются?

Для работы проекта требуются следующие библиотеки (они прописаны в файле `requirements.txt`):
1. **`scikit-learn`** — библиотека для машинного обучения (содержит модели классификации: логистическая регрессия, случайный лес, градиентный бустинг, а также метрики качества).
2. **`pandas`** — библиотека для работы с табличными данными (загрузка, предобработка и анализ датасетов).
3. **`joblib`** — инструмент для сохранения и загрузки обученных моделей на диск.
4. **`pytest`** — фреймворк для автоматического тестирования кода и проверки контрактов пайплайна.
